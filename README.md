# Gentle Piercing Warszawa

A modern, multilingual website for Gentle Piercing - medical ear piercing services in Warsaw.

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- React Router DOM
- i18next (multilingual support)

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd inverness-warszawa

# Step 3: Install the necessary dependencies
npm i

# Step 4: Start the development server
npm run dev
```

### Development

The development server will start on `http://localhost:8080` with hot module replacement.

### Building

```sh
# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

- `src/pages/` - Page components
- `src/components/` - Reusable components
- `src/lib/` - Utility functions and configurations
- `src/i18n/` - Internationalization configuration
- `public/locales/` - Translation files
- `content/blog/` - Blog articles (Markdown files)

## Features

- Multilingual support (Polish, English, Ukrainian, Russian)
- Static Site Generation (SSG) for SEO
- Blog content management via Decap CMS
- Optimized performance and loading speed
- Responsive design

## Deployment

The project is configured for deployment on Vercel with static site generation support.
